# Tip Calculator

**▶ [Try it live](https://theoyanvno.github.io/tip-calculator/)**

Type the bill, pick a tip and the number of people, and it shows the tip, the total and what each person pays. It updates as you type and warns about impossible numbers, like 0 people.

## What it shows

- Variables with `const`, strings and numbers, and `Number()`
- Small functions that return values (`tipAmount`, `perPerson`, `money`)
- Finding elements and changing their `textContent`
- `input` and `click` event listeners
- Guard clauses with `if` for bad input
- Tip buttons built from an array with a `for...of` loop

## Run it

Open `index.html` in a browser, or use VS Code's Live Server.
